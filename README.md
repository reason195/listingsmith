# ListingSmith AI

AI listing descriptions + Fair Housing compliance screening for real estate agents.

- Structured property form → MLS description (long + short), social post, and email subject lines
- Fair Housing screening: 81 risky phrases across 7 categories, with highlights and safer replacements (screening aid, not legal advice)
- Bring your own Gemini API key, or try the built-in demo mode
- Free: 1 full listing · Pro: $19/mo unlimited

Live site: https://reason195.github.io/listingsmith/
